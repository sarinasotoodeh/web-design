# IMDb Redesign

A front-end redesign of IMDb's homepage, movie page, review page, and sign-up flow.

## Overview

A solo front-end project redesigning key IMDb pages — homepage, a movie detail page, a review page, and a sign-up page — with a cleaner UI and progressive content reveal on data-heavy pages, using custom Bootstrap modals.

## Tech stack

HTML, SCSS/CSS, Bootstrap 5

## Pages

- `index.html` — homepage
- `movie.html` — movie detail page
- `review.html` — review page
- `sign-up.html` — sign-up page

## How to run

Open any of the HTML files above directly in a browser — no build step needed. (The `.scss` files are already compiled to the included `.min.css` files.)
